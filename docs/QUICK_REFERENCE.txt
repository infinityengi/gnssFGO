TECHNICAL INSIGHTS
═══════════════════════════════════════════════════════════════════════════════

Type2 Channel Design:
  • Type1 = Full L1 data
  • Type2 = L2 as offset from L1
  • Formula: L2 = L1 + MSB_offset * 256
  • Critical: MSB must be interpreted as signed int8_t

Multi-Signal Architecture:
  • Not all satellites have dual-frequency
  • SVID-based grouping essential
  • 40% observations are dual-frequency
  • 60% are single-frequency (L1 only)

Ephemeris Sources:
  Current: RINEX BRDC files (simple, cost-effective)
  Future:  SBF extraction from receiver (real-time, autonomous)
  Either:  Identical quality for FGO algorithm

Quality Filtering:
  • CN0 threshold: 25 dB-Hz (weak signal rejection)
  • Geometry quality: Satellite distribution
  • Ionosphere validation: L1-L2 consistency
  • FGO selection: 20% pass rate (conservative)
  • Purpose: Ensure only robust observations
